# Chapter 1: Getting Started with Python

## 📚 Learning Objectives

By the end of this chapter, you will be able to:
- Install Python on your computer (Windows, Mac, or Linux)
- Choose and set up a code editor (IDLE, VS Code, or PyCharm)
- Write and run your first Python program
- Understand the Python interactive shell (REPL)
- Use comments and the print() function effectively
- Create and save Python files (.py)

## 📂 Directory Structure

- **examples/** - Working code examples from the chapter
- **exercises/** - Practice exercises for you to complete
  - **solutions/** - Full solutions (try exercises first!)

## 🎯 What You'll Learn

This chapter introduces you to Python and gets you up and running with your first programs. You'll install Python, choose a code editor, and write the traditional "Hello, World!" program. By the end, you'll be comfortable running Python code both in the interactive shell and as saved files.

## 📝 Examples

- **01-hello-world.py** - Your first Python program with the classic "Hello, World!"
- **02-greeting-program.py** - A program that greets users with variables
- **03-interactive-shell-examples.py** - Quick calculations and tests in the Python shell

## ✏️ Exercises

- **exercise-01.py** - Print your name, age, and favorite hobby on separate lines
- **exercise-02.py** - Display your favorite quote with a comment noting the author
- **exercise-03.py** - Use the interactive shell to perform basic calculations
- **exercise-04.py** - Create simple text art using print statements
- **exercise-05.py** - Modify the greeting program with your own information

## 🚀 How to Use

1. Read Chapter 1 in the book
2. Run the examples: `python3 examples/01-hello-world.py`
3. Try the exercises: `python3 exercises/exercise-01.py`
4. Check solutions only after attempting: `python3 exercises/solutions/exercise-01-name-age-hobby.py`

## 💡 Tips

- Make sure to check the "Add Python to PATH" option during Windows installation
- Use IDLE or VS Code as a beginner - they're simple but powerful
- Save your code often and test as you go
- Don't worry about errors - they're part of learning!
- Create a dedicated folder for your Python projects to stay organized
