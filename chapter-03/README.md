# Chapter 3: Control Flow

## 📚 Learning Objectives

By the end of this chapter, you will be able to:
- Make decisions in your code with if, elif, and else statements
- Understand and use comparison and logical operators
- Repeat actions using for and while loops
- Use range() to generate number sequences
- Control loop execution with break and continue
- Work with nested loops for complex patterns
- Combine conditionals and loops effectively

## 📂 Directory Structure

- **examples/** - Working code examples from the chapter

## 🎯 What You'll Learn

This chapter teaches you how to control the flow of your programs. You'll learn to make decisions based on conditions and repeat actions with loops. These concepts are fundamental to creating dynamic, interactive programs that can solve real-world problems.

## 💡 Tips

- Indentation is CRITICAL in Python - use 4 spaces consistently
- Remember the colon (:) at the end of if, elif, else, for, and while statements
- Use `==` for comparison, not `=` (which is for assignment)
- Test your conditions with print statements to debug
- For infinite loops, make sure your while condition can become False
- Use `break` to exit a loop, `continue` to skip to the next iteration
- The range() function is exclusive of the stop value: range(5) gives 0,1,2,3,4
