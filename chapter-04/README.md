# Chapter 4: Functions & Modules

## 📚 Learning Objectives

By the end of this chapter, you will be able to:
- Define and call your own functions
- Use parameters to pass information to functions
- Return values from functions (including multiple values)
- Use default parameters and keyword arguments
- Understand variable scope (local vs global)
- Import and use Python's built-in modules (math, random, datetime)
- Create your own custom modules
- Document functions with docstrings

## 📂 Directory Structure

- **examples/** - Working code examples from the chapter
- **exercises/** - Practice exercises for you to complete
  - **solutions/** - Full solutions (try exercises first!)

## 🎯 What You'll Learn

Functions are the building blocks of organized, reusable code. This chapter teaches you to create functions that make your programs more efficient, readable, and maintainable. You'll also learn to leverage Python's extensive standard library through modules.

## 💡 Tips

- Function names should be descriptive and use snake_case
- Use docstrings to document what your functions do
- Avoid using global variables - use parameters and return values instead
- Test functions with different inputs to make sure they work
- Keep functions focused - each function should do one thing well
- The `self` parameter in methods refers to the instance (covered in Chapter 9)
- Import only what you need: `from math import sqrt` is better than `from math import *`
