## 🎯 How to Use This Repository

### 1️⃣ Read the Book
Start with Chapter 1 in "Learn Python Fast: From Zero to Coding Hero"

### 2️⃣ Run the Examples
```bash
cd chapter-01/examples
python3 01-hello-world.py
```

### 3️⃣ Try the Exercises
```bash
cd chapter-01/exercises
python3 exercise-01.py
```

Work on the exercise, then check your solution:
```bash
python3 solutions/exercise-01-name-age-hobby.py
```

### 4️⃣ Build Projects
Once you complete Chapters 1-9, try the projects in Chapter 10:
```bash
cd chapter-10/examples
python3 project-01-calculator.py
```

## 💡 Learning Tips

### For Complete Beginners
- **Follow chapter order** - Each chapter builds on previous concepts
- **Type code yourself** - Don't just copy/paste; typing helps memory
- **Try exercises before solutions** - Struggle is part of learning!
- **Experiment** - Modify examples to see what happens
- **Take breaks** - Learning to code takes time

### For Faster Learners
- **Skim familiar concepts** - Skip chapters you already know
- **Focus on exercises** - These test real understanding
- **Build your own projects** - Combine concepts creatively
- **Read others' code** - Compare your solutions to provided ones

### Common Mistakes to Avoid
- ❌ **Reading without coding** - You must write code to learn
- ❌ **Copying without understanding** - Know WHY code works
- ❌ **Skipping exercises** - These are where learning happens
- ❌ **Getting discouraged by errors** - Errors are your teachers!
