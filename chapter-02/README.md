# Chapter 2: Python Basics

## 📚 Learning Objectives

By the end of this chapter, you will be able to:
- Create and use variables properly with good naming conventions
- Work with different data types (integers, floats, strings, booleans)
- Convert between data types (type casting)
- Use arithmetic operators (+, -, *, /, //, %, **)
- Apply comparison operators (==, !=, <, >, <=, >=)
- Combine conditions with logical operators (and, or, not)
- Write clear, readable code with comments
- Get user input with the input() function

## 🎯 What You'll Learn

This chapter covers the fundamental building blocks of Python programming. You'll learn how to store information in variables, work with different types of data, and perform operations on them. You'll also master getting input from users and writing code that others can understand.

## 💡 Tips

- Use descriptive variable names like `student_count` instead of `sc`
- Remember: `=` assigns values, `==` compares them
- The `input()` function always returns a string - convert to int or float if needed
- Use type() to check what type a variable is if you're unsure
- Division (/) always returns a float, even for whole numbers
- Use the modulus operator (%) to check if numbers are even/odd
