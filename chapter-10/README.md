# Chapter 10: Python Projects for Beginners

## 📚 Learning Objectives

By the end of this chapter, you will be able to:
- Build complete applications from scratch
- Combine all Python concepts you've learned
- Structure larger programs effectively
- Implement data persistence (saving/loading)
- Design user-friendly command-line interfaces
- Debug and enhance existing projects
- Apply best practices to real-world problems

## 📂 Directory Structure

- **examples/** - Four complete project implementations
- **exercises/** - Space for you to enhance projects
  - **solutions/** - Additional enhancements (if any)

## 🎯 What You'll Learn

This is where everything comes together! You'll build four complete projects that combine classes, file I/O, error handling, data structures, and more. Each project solves a real problem and demonstrates professional programming practices. These projects are portfolio-ready examples of your Python skills.

## 📝 Complete Projects

### Project 1: Calculator with History
- **project-01-calculator.py** - Scientific calculator with history tracking
- Features: Basic operations, power function, calculation history, timestamps
- Concepts: Classes, datetime module, list management, menu systems

### Project 2: To-Do List Application
- **project-02-todo-list.py** - Complete task management system
- Features: Add/remove/complete tasks, priorities, JSON persistence, timestamps
- Concepts: Classes, file I/O, JSON, datetime, data modeling

### Project 3: Number Guessing Game
- **project-03-guessing-game.py** - Enhanced guessing game with stats
- Features: Multiple difficulty levels, statistics tracking, best scores
- Concepts: Random module, JSON persistence, game logic, statistics

### Project 4: File Organizer
- **project-04-file-organizer.py** - Automated file organization tool
- Features: Categorize by file type, dry-run mode, undo functionality
- Concepts: Pathlib, file operations, dictionaries, error handling

## 🚀 How to Use

1. Read Chapter 10 in the book
2. Study each project: `python3 examples/project-01-calculator.py`
3. Understand the code structure and flow
4. Try enhancing projects with new features
5. Build your own project combining learned concepts

## 💡 Tips

- Read through entire projects first before running them
- Pay attention to how code is organized into functions and classes
- Notice error handling and user input validation
- Study how data persistence is implemented
- Use these projects as templates for your own ideas
- Document your enhancements with comments
- Test thoroughly with different inputs
- Consider edge cases and handle them gracefully
